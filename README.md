# Metsanangwana Afterschool Programme

A lightweight, responsive website for an afterschool programme in Ga-Sekhukhune, Limpopo. The site introduces its arts and crafts, environmental education and computer classes at a village library.

The website is built with plain HTML, CSS and JavaScript. There are no packages to install and no build step.

## Open and edit the website

1. Open the `MEAN-Project` folder in Visual Studio Code.
2. Open `index.html` in a web browser to view the site.
3. Edit `index.html` for content, `styles.css` for appearance, or `script.js` for the mobile navigation and preview form behaviour.

## Add the files to GitHub

The [Metsanangwana-Project repository](https://github.com/segabutlelerato96-cpu/Metsanangwana-Project) is ready for its first upload:

1. Sign in to GitHub and open the repository.
2. Choose **Add file** → **Upload files**.
3. Upload `index.html`, `styles.css`, `script.js`, `README.md` and `render.yaml` from this folder.
4. Choose **Commit changes**.

## Publish the site on Render

This project includes a `render.yaml` Blueprint for a no-build static site.

1. Upload the project files to the GitHub repository.
2. In Render, choose **New** → **Blueprint** and select `segabutlelerato96-cpu/Metsanangwana-Project`.
3. Review the `metsanangwana-afterschool` static site and choose **Apply**.
4. When deployment finishes, open the `.onrender.com` address Render provides.

The site has no backend, database or secret configuration. The contact form is a preview only: it does not send, save or monitor messages. Add confirmed programme details and official contact information before publishing.
